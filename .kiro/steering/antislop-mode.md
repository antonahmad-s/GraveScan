# Antislop Mode

Use antislop in `during` mode for every GraveScan interface change. This is a project-specific instruction from the project owner.

- Do not add third-party images, logos, icon packs, or illustration assets unless the owner explicitly approves them.
- Use the existing UI direction: forensic incident room, evidence trails, ENERGY 2 / RHYTHM 3 / MOTION 1.
- Before delivery, run the antislop delivery gate plus the accessibility and responsive checks from `antislop-human` and `antislop-layoutmobile`.
