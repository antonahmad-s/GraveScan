Your project

Choose your project folder or its .kiro folder. GraveScan reads supported text files only. It does not upload files, run project code, or write to your repository.

  • Reads .json, .md, .yaml, .yml, and .txt files in the shallowest .kiro/ folder
  • Up to 500 files, 1 MiB each, and 5 MiB in total
  • Secret-like values are redacted before evidence, diffs, and reports are shown
