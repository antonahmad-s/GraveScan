Inspect the boundary before an agent crosses it.

GraveScan reads Kiro settings, hooks, agents, and steering files with deterministic rules. It can replay an available risk safely, propose an allowlisted patch, and verify the isolated copy.

Safe simulation. No arbitrary code or network request is executed.

  1. ReadEvidence names the file and line behind a rule match.
  2. ReplayAvailable risky capabilities are tested through a bounded simulation.
  3. VerifyAn isolated patch must survive another scan and replay.

Scan your .kiro configuration

GraveScan reads supported text files only. It does not upload files, run project code, or write to your repository.

  • JSON, Markdown, YAML, and text files in the shallowest .kiro/ folder
  • Up to 500 files, 1 MiB each, and 5 MiB in total
  • Secret-like values are redacted before evidence, diffs, and reports are shown
