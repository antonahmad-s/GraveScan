# Submission Checklist (Kiroween, Frankenstein)

Source: requirements pasted by the team. Re-check the official Rules tab before submitting.

## Repository
- [ ] Public GitHub repo (not GitLab or Bitbucket)
- [ ] LICENSE detected in the About section
- [ ] `/.kiro` at root, with specs, hooks, steering; NOT in `.gitignore`
- [ ] All source, assets, and run instructions included
- [ ] Fixtures labeled intentionally vulnerable; fake tokens only

## Deliverables
- [ ] Working app URL (credentials, if any, only in the Devpost form)
- [ ] Text description of features
- [ ] Demo video: under 3 minutes, public on YouTube, shows the app running
- [ ] No copyrighted music, no third-party trademarks or logos
- [ ] Kiro write-up (`docs/kiro-workflow.md`): IDE/CLI/Web/Crew, custom agents, hooks, specs vs vibe, steering, MCP, PBT, powers
- [ ] Category selected: Frankenstein; bonus prizes chosen if any

## Product
- [ ] Full flow works without login: scan, replay, patch, apply to copy, rescan, report
- [ ] Every button has behavior; loading/empty/error/success states exist
- [ ] Public deploy accepts no uploads and runs no user code
